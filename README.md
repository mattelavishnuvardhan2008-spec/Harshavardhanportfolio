# 🚀 Harsha — Digital Designer & Creative Developer Portfolio

A sleek, modern, single-page portfolio website designed and developed for **Harsha** (Digital Designer & Creative Developer). Built with clean semantic HTML5 and modern CSS3 featuring CSS Grid, Flexbox, CSS Variables, and responsive typography.

## ✨ Features

- 🎨 **Modern Editorial Design:** Eye-catching brutalist-influenced typography paired with clean layout grids.
- 📱 **Fully Responsive:** Tailored layouts for desktop, tablet, and mobile viewports with a collapsible navigation drawer.
- ⚡ **Zero External JS Dependencies:** Lightweight, blazing-fast performance built entirely with vanilla HTML and CSS.
- 🔁 **Micro-Interactions & Animations:**
  - Sticky glassmorphism navigation bar.
  - Infinite marquee ticker strip.
  - Interactive service rows with dynamic hover transformations.
  - Custom keyframe-animated pulse indicators.
  - Smooth native page scrolling (`scroll-behavior: smooth`).
- 🛠️ **Structured Sections:**
  - **Hero & Intro:** Headline, key skills list, photo frame, and quick stat counters.
  - **About:** Personal statement and numerical highlights.
  - **Services:** Interactive service breakdown with tagged expertise.
  - **Portfolio/Works:** Grid layout showcasing selected projects.
  - **Awards & Testimonials:** Client social proof and industry recognition.
  - **Contact:** Clean form interface with social links.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** CSS3 (Variables / Custom Properties, Grid, Flexbox, Keyframes)
- **Typography:** Google Fonts (`Archivo`, `Space Grotesk`, `Inter`)
- **Icons & Graphics:** Inline Base64 Data URIs / Standard Unicode symbols
